# Food Delivery Management System – QA Portfolio

## Project Overview
This repository contains the QA work for a web and mobile-based Food Delivery Management System, developed as a second-year group project.  
My role focused on **Quality Assurance (QA)**, including **manual testing**, **test case design**, and **bug reporting using JIRA**.

---

## My Role
- Designed and executed structured **manual test cases** for both web and mobile applications.  
- Identified, reported, and tracked defects using **JIRA**, including severity and priority levels.  
- Collaborated with the development team to validate bug fixes and ensure application stability and usability.  
- Provided support for development of the web and mobile application.

---

## Tools & Technologies
- **Manual Testing & Test Case Design:** Microsoft Excel  
- **Bug Tracking:** JIRA  
- **Version Control:** Git, GitHub  
- **Applications Tested:** Web & Mobile Food Delivery System  

---

## JIRA Bug Reporting
Defects were logged and tracked in JIRA, including:
- Clear steps to reproduce  
- Expected vs Actual results  
- Severity and priority

## How to Use
1. Open the FoodDelivery_Web_TestCases.xlsx or FoodDelivery_Mobile_TestCases.xlsx files to view detailed manual test cases for each platform.
2. Browse the `Jira_Bug_Reports` folder to see sample bug reports logged in JIRA.  
3. Use this repository as a reference for **manual QA processes**, **bug reporting**, and **test documentation**.
